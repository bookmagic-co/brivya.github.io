## 从这里开始

Brivya 是开源 Business-to-Agent 基础设施。它将真实业务能力定义为类型化契约，通过同一受治理运行时连接 REST、MCP 与平台分发生态。



如果第一次使用 Brivya，先完成快速开始，再阅读架构和 Restaurant 示例。已有 TypeScript 项目可以从 SDK 与协议适配器开始。

## 开发路线

- [快速开始](https://brivya.com/docs/quickstart/)：安装 CLI，生成并验证业务 Manifest。
- [架构与安全](https://brivya.com/docs/architecture/)：理解业务契约、运行时和平台投影。
- [TypeScript SDK](https://brivya.com/docs/sdk/)：使用 canonical 类型和运行时。
- [协议与平台适配](https://brivya.com/docs/adapters/)：通过 REST、MCP 和参考分发配置接入生态。
- [Restaurant 示例](https://brivya.com/docs/restaurant/)：运行已有的端到端业务契约测试。
