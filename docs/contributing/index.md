# 参与贡献与安全

帮助完善业务契约、开发工具和多平台一致性。

Canonical: https://brivya.com/docs/contributing/
Version: 0.1.0-alpha.1
Language: zh

## 贡献路径

欢迎通过源码仓的 issue 与 Pull Request 参与。较大的功能先讨论问题、范围与兼容性；实现应保持协议中立、模型中立、类型化能力和明确策略边界。


- 创建 feature 分支并聚焦单一改动。
- 实现行为变更时补充测试和公开文档。
- 运行 npm run ci 与相关发布就绪检查。
- 提交 PR，说明问题、行为、验证和兼容性影响。

## 安全报告

潜在漏洞应按照公开仓 SECURITY.md 的渠道私下报告。不要在公开 issue 中贴出凭据、客户数据或敏感漏洞细节。



[查看安全报告渠道 ↗](https://github.com/brivya/brivya/blob/main/SECURITY.md)
