02 / START BUILDING

从第一份
业务契约开始。

安装 CLI，生成 Manifest，再验证你的业务定义。Node.js 20 或更高版本即可开始。

当前为 Alpha：公开 API 仍可能变化。dev 验证本地配置；业务执行由 BusinessRuntime 提供。

探索 Restaurant 端到端示例 →
Quick Start / shell
# 安装 Alpha CLI
npm install -g @brivya/cli@0.1.0-alpha.1

# 创建并验证业务契约
mkdir my-business
cd my-business
brivya init
brivya validate
brivya inspect
brivya dev
