02 / START BUILDING

Start with your
first business contract.

Install the CLI, generate a Manifest and validate your business definition. Start with Node.js 20 or newer.

Alpha APIs may change.dev validates local configuration; BusinessRuntime owns execution.

Explore the Restaurant reference →
Quick Start / shell
# Install the Alpha CLI
npm install -g @brivya/cli@0.1.0-alpha.1

# Create and validate a business contract
mkdir my-business
cd my-business
brivya init
brivya validate
brivya inspect
brivya dev
