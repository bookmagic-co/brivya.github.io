Start here

Brivya is open Business-to-Agent infrastructure. It models real business capabilities as typed contracts and connects REST, MCP and distribution ecosystems through one governed runtime.

New to Brivya? Start with the CLI, then explore the architecture and Restaurant reference. Existing TypeScript applications can begin with the SDK and protocol adapters.

Developer journey

  1. Quick Start: generate and validate a business Manifest.
  2. Architecture and safety: understand contracts, runtime and projections.
  3. TypeScript SDK: use canonical types and execution.
  4. Protocols and platforms: connect REST, MCP and reference distribution profiles.
  5. Restaurant reference: run the existing end-to-end contract tests.
