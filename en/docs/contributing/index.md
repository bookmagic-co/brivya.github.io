Help improve business contracts, developer tools and platform conformance.

Canonical: https://brivya.com/en/docs/contributing/
Version: 0.1.0-alpha.1
Language: en

## Contributing

Contribute through issues and Pull Requests in the public implementation repository. Discuss substantial changes first. Preserve protocol and model neutrality, typed capabilities and explicit policy boundaries.


- Create a feature branch for a focused change.
- Add tests and public documentation for behavior changes.
- Run npm run ci and relevant release checks.
- Describe the problem, behavior, validation and compatibility in a PR.

## Security reports

Report potential vulnerabilities privately through the channels in SECURITY.md. Never post credentials, customer data or sensitive vulnerability details in public issues.



[Security reporting channels ↗](https://github.com/brivya/brivya/blob/main/SECURITY.md)
