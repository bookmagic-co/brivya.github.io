# Documentation

## Start here

Brivya is open Business-to-Agent infrastructure. It models real business capabilities as typed contracts and connects REST, MCP and distribution ecosystems through one governed runtime.



New to Brivya? Start with the CLI, then explore the architecture and Restaurant reference. Existing TypeScript applications can begin with the SDK and protocol adapters.

## Developer journey

- [Quick Start](https://brivya.com/en/docs/quickstart/): generate and validate a business Manifest.
- [Architecture and safety](https://brivya.com/en/docs/architecture/): understand contracts, runtime and projections.
- [TypeScript SDK](https://brivya.com/en/docs/sdk/): use canonical types and execution.
- [Protocols and platforms](https://brivya.com/en/docs/adapters/): connect REST, MCP and reference distribution profiles.
- [Restaurant reference](https://brivya.com/en/docs/restaurant/): run the existing end-to-end contract tests.
